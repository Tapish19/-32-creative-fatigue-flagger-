After reviewing the plan, the user instructed: "make a new folder named \"newproject\" and start implementing this inside that folder".

The official CSV download initially failed. The user then provided `mm-ai-engineer-challenge-SAMPLE-DATA.csv` locally. The file was bundled in the app and every creative's metrics were checked against an independent Python calculation. A sample regression test was added.

The user then requested publishing the project to their GitHub account.

Implementation decisions and calculation interpretations are recorded in README.md.
